# 未分類 — 要件


## ナビゲーションコンテキスト

ユーザーはCOSGN00Cサインオン画面を通じてアプリケーションに入り、ユーザーIDとパスワードで認証を行った後、ユーザータイプに基づいて管理者メニュー（COADM01C）または一般ユーザーメニュー（COMEN01C）のいずれかにルーティングされる。メニュープログラム内では、ユーザーは番号付きオプションを選択し、CICS XCTL転送を介して特定の機能領域へ前進的にナビゲートし、通信エリアが画面間でトランザクションおよびプログラムコンテキストを運ぶ。メニュー階層のどの時点でも、PF3を押下するとユーザーはサインオン画面に戻り、現在のセッションコンテキストが実質的に終了して再認証または再入力が必要となる。宛先プログラムが利用不可または未インストールの場合、ユーザーは転送されることなく、適切なエラーメッセージとともに現在のメニューに留まる。


## グローバル前提条件

- 有効なCICS環境がアクティブであり、XCTLプログラム転送およびBMS画面インタラクションを処理可能でなければならない
- ユーザーセキュリティファイル（AWS.M2.CARDDEMO.USRSEC.VSAM.KSDS）は、認証済みナビゲーションに先立って読み取り操作のためにアクセス可能かつ利用可能でなければならない
- 有効な通信エリア（COMMAREA）が存在し、サインオン後のすべてのナビゲーションに対して発信元トランザクションIDおよびプログラム名が正しく設定されていなければならない。COMMAREAが存在しないまたは空である場合、サインオン画面への自動リダイレクトが発生する
- ユーザーは、COADM01CまたはCOMEN01Cのいずれかにアクセスする前に、COSGN00Cを通じて正常に認証を完了していなければならない。未認証のアクセス試行はサインオン画面にリダイレクトされる
- 正しいメニュールーティングおよびオプション権限付与を判定するために、ユーザーのタイプ分類（管理者か一般ユーザーか）がセキュリティレコードから解決可能でなければならない
- メニューオプションによって参照されるすべての対象プログラムは、CICSプログラムインベントリ内に登録されていなければならない。未登録のプログラムは、転送ではなく「未インストール」状態を引き起こす
- 各表示サイクルで画面ヘッダーフィールドに値を設定するために、日付および時刻サービスが利用可能でなければならない


## 1. サインオン資格情報の収集と検証
エンドユーザーとして、サインオン画面で資格情報を送信し、システムが自分を認証して適切なメニューにルーティングできるようにしたい。

### 要件

REQ-F-001: [Ubiquitous] システムは、入力を受け取る前に検証エラーが想定されないよう、プログラム開始時にエラーフラグをオフ状態に初期化しなければならない。

REQ-F-002: [Event-driven] サインオン画面が表示される場合、システムは、MM/DD/YY形式でフォーマットされた現在日付、HH:MM:SS形式でフォーマットされた現在時刻、アプリケーションタイトル行、トランザクション識別子、およびプログラム名を画面ヘッダーに設定し、ユーザーに画面を提示する前に、画面出力領域に保留中のエラーメッセージがあれば含めなければならない。

REQ-F-003: [Event-driven] ユーザーがサインオン画面でEnterキーを押下した場合、システムはサインオン資格情報処理ロジックにルーティングしなければならない。

REQ-F-004: [Event-driven] ユーザーがサインオン画面でEnter以外のキーを押下した場合、システムはエラーメッセージ「Invalid key pressed. Please see below...」を表示し、サインオン画面を再表示しなければならない。

REQ-F-005: [Event-driven] ユーザーがサインオンフォームを送信し、ユーザーIDフィールドが空（スペースまたはlow-values）である場合、システムはエラーフラグをオンに設定し、メッセージ「Please enter User ID ...」を表示し、サインオン画面を再表示しなければならない。

REQ-F-006: [Event-driven] ユーザーがサインオンフォームを送信し、パスワードフィールドが空（スペースまたはlow-values）である場合、システムはエラーフラグをオンに設定し、メッセージ「Please enter Password ...」を表示し、サインオン画面を再表示しなければならない。

REQ-F-007: [Event-driven] ユーザーIDとパスワードの両フィールドが空でない場合、システムは両方の値を大文字に変換して保存した後、ユーザーセキュリティデータストア（AWS.M2.CARDDEMO.USRSEC.VSAM.KSDS）に対する資格情報検証に進まなければならない。

## 2. セキュリティデータストアに対するユーザー認証
エンドユーザーとして、自分の資格情報がセキュリティデータストアに対して検証され、有効なユーザーのみがアプリケーションへのアクセスを得られるようにしたい。

### 要件

REQ-F-008: [Event-driven] 両方の資格情報が収集され、空でないことが検証された場合、システムは、ユーザーID（英数字最大8文字）をキーとして、ユーザーセキュリティデータストア（AWS.M2.CARDDEMO.USRSEC.VSAM.KSDS）内のユーザーレコードを検索しなければならない。

REQ-F-009: [Event-driven] ユーザーレコードが見つかり、保存されているパスワードが入力されたパスワードと一致しない場合、システムはメッセージ「Wrong Password. Try again ...」を表示し、サインオン画面を再表示しなければならない。

REQ-F-010: [Event-driven] ユーザーセキュリティデータストア内にユーザーレコードが見つからない場合、システムはメッセージ「User not found. Try again ...」を表示し、サインオン画面を再表示しなければならない。

REQ-F-011: [Event-driven] ユーザーセキュリティデータストアの読み取り中にシステムエラーが発生した場合、システムはメッセージ「Unable to verify the User ...」を表示し、サインオン画面を再表示しなければならない。

## 3. 認証済みユーザーのセッションルーティング
認証済みユーザーとして、自分のユーザータイプに基づいて正しいメニューにルーティングされ、自分の役割に適した機能のみにアクセスできるようにしたい。

### 要件

REQ-F-012: [Event-driven] 保存されているパスワードが入力されたパスワードと一致する場合、システムは、ユーザーセキュリティデータストアから取得した認証済みユーザーのトランザクション識別子、プログラム名、ユーザーID（英数字最大8文字）、およびユーザータイプ（英数字1文字）をセッションコンテキストに設定しなければならない。

REQ-F-013: [Event-driven] 認証済みユーザーのユーザータイプが管理者を示す場合、システムは、設定済みのセッションコンテキストを渡して、管理者メニューに制御を転送しなければならない。

REQ-F-014: [Event-driven] 認証済みユーザーのユーザータイプが管理者を示さない場合、システムは、設定済みのセッションコンテキストを渡して、一般メニューに制御を転送しなければならない。

## 4. 管理者メニューの初期化とナビゲーション（COADM01C）
管理者として、管理メニューが正しく初期化され、自分の入力がルーティングされることで、管理機能を選択して起動できるようにしたい。

### 要件

REQ-F-015: [Event-driven] 事前のセッションコンテキストなしで管理者メニュープログラムが呼び出された場合、システムは直ちにサインオン画面プログラムに制御を転送しなければならない。

REQ-F-016: [Event-driven] セッションコンテキストが存在する状態で管理者メニュープログラムが呼び出された場合、システムはセッションコンテキストデータをローカルレコード構造に読み込まなければならない。

REQ-F-017: [Event-driven] 管理者メニュープログラムに入り、プログラムコンテキストが再入場を示していない場合、システムは管理メニュー画面を表示しなければならない。

REQ-F-018: [Event-driven] 管理者メニュープログラムに再入場し、ユーザーがEnterを押下した場合、システムはメニュー画面の入力を受け取り、オプション検証処理にルーティングしなければならない。

REQ-F-019: [Event-driven] 管理者メニュープログラムに再入場し、ユーザーがEnterまたはPF3以外のキーを押下した場合、システムは無効キーメッセージを表示し、管理メニュー画面を再表示しなければならない。

REQ-F-020: [Event-driven] ユーザーが管理メニューでメニューオプションを送信した場合、システムは、オプション入力の末尾スペースを削除し、内部のスペースをゼロに置き換え、その結果を数値のオプション番号に変換し、その値が数値であり、ゼロより大きく、利用可能な管理者オプションの最大数を超えないことを検証しなければならない。

REQ-F-021: [Event-driven] 送信されたメニューオプションが検証に失敗した場合（非数値、ゼロ、または管理者オプションの最大数を超える場合）、システムはエラーフラグをアクティブに設定し、メッセージ「Please enter a valid option number...」を表示し、管理メニュー画面を再表示しなければならない。

REQ-F-022: [Event-driven] メニューオプションのナビゲーション中にプログラムが見つからない状態が発生した場合、システムはメッセージ「This option is not installed ...」を表示し、管理メニュー画面を再表示しなければならない。

REQ-F-023: [Event-driven] ユーザーが管理者メニューでPF3を押下した場合、システムは宛先プログラムをサインオン画面プログラムに設定し、それに制御を転送しなければならない。

REQ-F-024: [Event-driven] 制御転送前に宛先プログラム名が空または未設定である場合、システムは宛先プログラム名をサインオン画面プログラムにデフォルト設定しなければならない。

REQ-F-025: [Ubiquitous] システムは、セッションコンテキストのナビゲーション対象に指定された宛先プログラムに制御を転送しなければならない。
